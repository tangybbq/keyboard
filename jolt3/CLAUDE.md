# Jolt3 keyboard designs

This directory contains the KiCad files for my Jolt3 keyboards.  The overall design is described in
README.md.

There are three PCBs here:

  - jolt3-left - The left-side main pcb
  - jolt3-right - The right-side main pcb
  - j3-mez-2040 - A mezzanine board with the rp2040 as the CPU

These boards are built around the same small vertical board segments as the jolt2 (../jolt2),
specifically, the jolt2-verts boards.
